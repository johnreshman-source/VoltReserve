# VoltReserve - IoT-Based EV Charging Slot Reservation System

A full-stack application for managing electric vehicle charging station reservations with real-time IoT monitoring.

## 🚀 Features

- **Smart Reservation System**: Reserve EV charging slots for 30 minutes
- **Real-Time Monitoring**: IoT sensors track port occupancy in real-time
- **QR Code Verification**: Unique QR codes for each reservation
- **Distance-Based Search**: Find stations within 2km radius
- **Live Status Updates**: See port availability instantly
- **Booking History**: Track all your charging sessions
- **Admin Dashboard**: Monitor system health and activity
- **OpenChargeMap Integration**: View public charging stations
- **Mobile Friendly**: Fully responsive design
